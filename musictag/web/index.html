Reading a quality badge

70Serious
70 — the overall score
Serious — the worst single problem found

They are two different things, which is why a file can read 94 · Minor or 70 · Serious.

The number: how much is wrong in total

Every file starts at 100. Each finding deducts points according to how serious it is. A file with nothing wrong stays at 100.

The word: how bad the worst problem is

A file can score well overall and still have one serious fault worth acting on. The word tells you whether anything needs your attention.

Nothing here changes your files — it is a report. Expand any row to see exactly what was measured and why each finding was raised.

Settings

Acoustic fingerprinting

Fingerprinting identifies a track from the audio itself, so it works even when the file has no tags and a meaningless name. It needs a free AcoustID key and the fpcalc tool. Without them the app falls back to matching on existing tags and filenames.

MusicBrainz

A failed or empty lookup is remembered for up to 30 days so re-scanning doesn't hammer MusicBrainz with the same question. If a track's confidence looks wrong because a lookup should have found something and didn't, clear the cache and run Tag again to force every lookup fresh.

Confidence thresholds

How Plex reads your library

Plex uses embedded tags to identify and group music, and folder structure as its fallback and for artist/album browsing. This app writes both. The field that matters most is album artist — without it, a compilation splits into one album per track artist.

Audio analysis

Decodes each file and measures it: spectral roll-off (which exposes fake lossless files and inflated bitrates), clipping, clicks and pops, mid-track dropouts, and tracks that stop before they should. Needs ffmpeg.

Updates

Asks GitHub once every few hours whether a newer MusicTagger has been released, and shows a banner if so. Nothing is ever downloaded or installed automatically - the banner links to the release and you decide. This is the only request the app makes on its own initiative rather than because you asked it to look something up.

Change history

Every batch of writes is journalled. Undo restores the previous tags and moves files back where they came from.
